# LED-Analog-Watch

**72個のLEDで時刻を表示する、オリジナル腕時計の開発プロジェクト。**

## 概要

`LED-Analog-Watch` は、72個のLEDを円形に配置し、アナログ時計のように時刻を表示する腕時計を一から設計・製作するプロジェクトです。

独自の電子回路・PCB・ファームウェアを開発し、市販の金属製ケース・金属製時計バンドと組み合わせることで、実用性とデザイン性を両立した腕時計を目指します。

## 開発目標

- 72個のLEDを円形に配置した表示機構の設計
- 時刻表示に必要な電子回路とカスタムPCBの開発
- マイコンとリアルタイムクロック（RTC）を用いた時刻管理
- 市販の金属製ケース・金属製時計バンドとの統合
- 電子回路から機構設計、組み立てまでの開発過程の記録

## ハードウェア設計

本プロジェクトでは、腕時計としてのサイズや外観を考慮しながら、電子回路と基板を独自に設計します。

主な設計対象は以下のとおりです。

- 72個のLEDによる円形表示回路
- マイコンおよびRTCによる時刻管理回路
- LED駆動回路
- 電源回路および電池接続部
- プログラム書き込み・時刻設定用インターフェース
- ケース内部への基板固定構造

PCBの設計では、LEDの配置や視認性だけでなく、ケース内部の寸法、部品の高さ、電池交換のしやすさも考慮します。

## 参考プロジェクト

### LED_round_watch — Taifur氏

[OSHWLab: LED_round_watch](https://oshwlab.com/taifur/led_round_watch)

本プロジェクトの着想を得た参考プロジェクトです。

72個のLEDを円形に配置し、マイコンとRTCを用いて時刻を表示する腕時計が製作されています。公開されている設計情報から、LED配置、電子回路、基板設計、ファームウェア、市販時計ケースへの組み込み方法などを参考にします。

**参考プロジェクトの主な構成**

- 72個のLEDによる円形表示
- ATmega328Pマイコン
- DS3231系RTC
- 直径約40 mmの円形PCB
- 市販のステンレス製時計ケース
- Arduinoスケッチによる制御

本プロジェクトでは、これらの情報を参考にしながら、独自の回路・PCB・ファームウェア・金属製ケースを設計します。参考プロジェクトの設計データをそのまま自作成果物として扱うことはしません。
